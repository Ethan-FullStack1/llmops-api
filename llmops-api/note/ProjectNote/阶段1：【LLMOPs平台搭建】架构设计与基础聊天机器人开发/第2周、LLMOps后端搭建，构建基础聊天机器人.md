#### 2、维护状态

> 可以看到这里面是存在三个维护状态
>
> prerelease
>
> bugfix
>
> security
>
> prerelease是预发布的状态，一般在这个状态下的版本都是最新的版本，他会含有python的一些最新的特性，如果是作为个人学习使用的话，建议使用预发布版本，也就是3.13的版本，
>
> bugfix是维护状态的版本，他一般是安全版本与预发布版本之间的一个过渡版本，在此期间发现的一些BUG他会去作一些维护，这个版本一般使用的比较少。
>
> security是安全版本，安全版本顾名思义就是这个版本下他的表现会相当的稳定，而且该修复的BUG他都已经修复了，而且支持的时间长度一般是比较长的。比如3.10、3.9还有就是3.8的版本都是安全版本。
>
> 安全版本是比较适合在生产环境下去使用的。他的特性可能说没有新版本那么多，但是使用起来更加的稳定。目前市面上大部分的包都是支持安全版本的。
>
> 但是预发布版本可能不支持其中的某些特性。
>
> 所以说就建议，如果个人学习，可以安装3.13，如果是在公司生产环境下去使用，尽可能去使用3.10或者是3.10以下的版本。
>
> 这里的话，我们就会安装3.10的版本。他的首次发布时间是2021-10-04，终止支持时间是2026-10

### 4、Python虚拟环境的创建与优缺点

+ 创建虚拟环境命令：<font color="red">python -m venv 环境名</font>，该命令在Python 2.7+或Python 3.3+以上可以使用。

> 为什么不考虑去全局安装，而是去创建一个虚拟的环境呢？这样子会不会多此一举？

+ Python的<font color="red">虚拟环境与系统环境之间是隔离的</font>，一个项目一个虚拟环境，不同的虚拟环境不会相互影响，最大程度避免包冲突。

> 虚拟环境与系统环境之间是隔离的，是什么意思呢？前面安装的环境是整个python系统的环境，如果你在这里面调用pip去安装指定的包，比如说安装了openai的包，那么这个包是整个系统他共享的。这种情况就可能有一种问题，比如说项目A他需要的版本是openai2.0对吧，然后项目B需要的版本是openai1.0，就可能会导致项目的包冲突。但是如果你创建了虚拟环境的话，一个项目他是会制定一个虚拟环境的，不同虚拟环境之间他们是不会相互影响的。最大程度上可以去避免包的冲突。这是他的一个优点，也是非常明显的。、
>
> 虚拟环境的缺点也是很明显的。

+ 占用更大的空间(如果两个项目他们用的包是同一个的话，那么虚拟环境它会复制两份，所以它占用空间会更大，特别是某些机器学习的包 ，他的整个大小可能会有1-2GB，如果创建的项目比较多，很可能硬盘上几百个GB都是这些Python包)，进入虚拟都需要使用命令activate激活才能使用，使用完，要使用deactivate命令退出。

### 5、腾讯云pip镜像加速配置

> 当使用pip去下载python包的时候，他默认链接的是外国的网站，众所周知在国内去使用会比较慢，甚至在很多情况下是没有办法去连接的，所以需要将pip去配置一个镜像源，让pip去连接国内的网站，去下载这些Python包。所以镜像加速原理很简单，国内的大企业做了很多社区，比如说像腾讯做了pip的镜像网站，他就拷贝了整个pip的所有内容，让pip可以直接连接到腾讯的网站上进行下载，所以下载速度就会很快。

+ 镜像加速原理，国内网站拷贝了整个pip的所有包，让pip直接连接到国内网站下载，下载会更快。
+ 临时使用：

```shell
pip install -i 镜像地址 <some-package>
```

> 临时使用的意思是在安装某个包的时候，使用pip install 跟上-i 还有镜像地址，这个时候就可以从镜像地址下载指定的包了，但是这种操作他是每一次下载或者是每一次更新某个包都需要去配置，非常的麻烦。所以推荐全局配置

+ 全局使用：

```shell
pip config set global.index-url 镜像地址
```

> 全局配置的意思是只需要配置一次，后续正常的安装，他默认就会从镜像地址里面去下载。

+ 镜像

```shell
https://mirrors.cloud.tencent.com/pypi/simple
```

+ 下面就进行配置，打开刚刚的命令行，切换到对应的虚拟环境下。

![image-20260620142824252](typora_img/image-20260620142824252.png)

+ 然后输入以下命令

```shell
pip config set global.index-url https://mirrors.cloud.tencent.com/pypi/simple
```

![image-20260620143016029](typora_img/image-20260620143016029.png)

+ 回车之后就已经将配置文件写入了，如何验证配置已经生效呢？输入以下命令

```shell
pip config list
```

![image-20260620143129857](typora_img/image-20260620143129857.png)

+ 此时就输出了所有的配置信息，这里它展示了全局的索引加速地址是腾讯的地址。
+ 这个时候，再去安装包他的速度就会非常的快了。
